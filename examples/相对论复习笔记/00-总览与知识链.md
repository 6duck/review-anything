# 00 · 狭义相对论总览与知识链

> [!abstract] 一句话
> 狭义相对论回答的是：**当"一切物理规律在任何惯性系中形式相同"和"真空中光速对任何惯性系都等于 $c$"同时被当作公理时，时间和空间会变成什么样** —— 代价是绝对同时性被放弃，收益是洛伦兹变换、质能关系 $E=mc^2$ 和一套在高速下仍然正确的动力学。本章只处理**惯性系**内的高速运动规律。

## ① 知识链（谁依赖谁）

```text
                        牛顿绝对时空观（时间、长度、质量均与参考系无关）
                                    │
                          伽利略变换 + 力学相对性原理
                                    │  力学规律不变 ✓
                                    │  电磁规律不变 ✗ —— 光速在伽利略变换下会变成 c±v
                                    │
                    迈克耳孙–莫雷实验（以太漂移的"零结果"）
                                    │
                    ┌───────────────┴────────────────┐
                    │  两条基本原理（1905）           │
                    │  1 相对性原理  2 光速不变原理    │
                    └───────────────┬────────────────┘
                                    │  "同时"不再绝对
                                    ▼
                        洛伦兹变换（时空坐标正/逆变换）
        ┌────────────────┬──────────┴──────────┬─────────────────┐
        ▼                ▼                     ▼                 ▼
   同时性的相对性     时间延缓             长度收缩         洛伦兹速度变换
   Δt'=γ(Δt-vΔx/c²)   Δt=γτ₀              L=L₀/γ            u=(u'+v)/(1+u'v/c²)
        └────────────────┴─────────────────────┘                 │
                                    ▼                            │
                       相对论质量 m=γm₀ 与动量 p=γm₀v  ◀──────────┘
                                    │
                                    ▼
                 相对论动能 Eₖ=mc²-m₀c²  →  质能关系 E=mc²
                                    │
                                    ▼
                  能量–动量关系 E²=p²c²+m₀²c⁴（+ 光子 E=pc）
                                    │
                                    ▼
                 碰撞 / 衰变 / 质量亏损 / 极限速率（动力学应用）
```

> [!tip] 全章只有一个"发动机"
> 所有看似离散的结论（同时性相对性、钟慢、尺缩、速度变换上限）都是**同一条洛伦兹变换**在不同侧面上的投影。考试里凡是"记不清该用哪个公式"，先问：**这是求坐标/时间（用洛伦兹变换），还是求同一事件在两个系中的速度（用速度变换）？**

## ② 概念职责表（谁负责什么、不负责什么）

| 概念 | 负责 | 不负责 |
|---|---|---|
| 伽利略变换 | 低速（$v \ll c$）下惯性系间的坐标、速度换算 | 高速情形；电磁现象 |
| 相对性原理 | 断言"没有特殊的惯性系"，一切惯性系平权 | 说明光速是多少 |
| 光速不变原理 | 给变换式提供唯一的"标定尺"，使 $x=ct \Leftrightarrow x'=ct'$ | 断言光的传播**方向**不变（方向会变，见 [[08-洛伦兹速度变换]]） |
| 洛伦兹变换 | 事件时空坐标 $(x,t)\to(x',t')$ 的换算 | 直接给"长度""寿命"等导出量（那是它的推论） |
| 时间延缓 | 用一个钟测得的**原时**与两个钟测得的**测时**之差 | 判断"谁真的更年轻"（那要引入非惯性系，见双生子佯谬） |
| 长度收缩 | 沿相对运动方向、**同时测**两端的长度之比 | 垂直方向（垂直方向长度不变）；"看起来"的样子（视觉效应另算） |
| 相对论质量 | 使动量守恒在洛伦兹变换下仍成立 | 解释成"物质变多了"（质量增加只是动能/相互作用能的量度） |
| 能量–动量关系 | 用 $E$、$p$ 统一描述粒子，包括 $m_0=0$ 的光子 | 替代动量守恒与能量守恒（两者仍各自独立使用） |

## ⑤ 记号总表（全章统一，只在这里定义一次）

| 记号 | 含义 | 说明 |
|---|---|---|
| $S$、$S'$ | 两个惯性系 | $S'$ 相对 $S$ 以恒定速度 $v$ 沿 $x$ 轴正方向运动；两原点重合且钟读数置零时为计时起点 |
| $v$ | $S'$ 相对 $S$ 的速度 | 只沿 $x$ 方向，故 $v$ 是代数量（可正可负） |
| $\beta$ | $\beta = v/c$ | 无量纲，$\lvert\beta\rvert < 1$ |
| $\gamma$ | $\gamma = 1/\sqrt{1-v^2/c^2} = 1/\sqrt{1-\beta^2}$ | 洛伦兹因子/时间膨胀因子，$\gamma \geqslant 1$；$\gamma(0)=1$ |
| $u$、$u'$ | 同一质点（事件）在 $S$、$S'$ 中的速度 | 有 $x,y,z$ 三个分量；与参考系速度 $v$ 不同，别混 |
| $\tau_0$ | 原时（固有时） | 与事件同地的那只钟测得的间隔；**原时最短** |
| $\Delta t$ | 测时（两地时） | 用两只同步钟测得的间隔 |
| $L_0$ | 原长（固有长度） | 杆静止时测得的长度；**原长最长** |
| $L$ | 测长 | 在相对杆运动的系中、**同时**测两端所得长度 |
| $m_0$、$m$ | 静质量、相对论质量 | $m=\gamma m_0$ |
| $E_0$、$E_k$、$E$ | 静能、动能、总能量 | $E_0=m_0c^2$，$E_k=E-E_0$，$E=mc^2$ |
| 约定 | 除非特别说明，取 $c=3\times10^{8}\ \mathrm{m/s}$ | 课件所有数值例题均按此取整 |

## ⑦ 疑难速查（复习时最常卡住的点）

| 问题 | 一句话答案 | 详见 |
|---|---|---|
| 钟慢效应里，哪个是"原时"？ | 与两事件**同地**的那只钟测到的就是原时，原时永远最短 | [[06-时间延缓与双生子佯谬]] |
| 尺缩只发生在运动方向吗？ | 是。垂直方向长度不变，所以正方形会变成菱形（面积缩小） | [[07-长度收缩]] |
| $0.8c$ 的飞船再发射 $0.9c$ 的物体，地面看到多少？ | $0.99c$，用速度变换而不是 $1.7c$ | [[08-洛伦兹速度变换]] |
| $E=mc^2$ 是说质量可以变成能量吗？ | 它是说"质量本身就是能量的一种量度"；质量亏损对应的能量释放只是账面换算 | [[10-相对论动能与质能关系]] |
| 光子没有静质量，为什么有动量？ | $E^2=p^2c^2+m_0^2c^4$ 在 $m_0=0$ 时给出 $E=pc$ | [[11-能量动量关系与相对论碰撞衰变]] |
| 双生子到底谁年轻？ | 返回的那个年轻；关键是飞船**有加速度**，不是惯性系，狭义相对论不能直接用在对等地位上说"双方都看对方年轻" | [[06-时间延缓与双生子佯谬]] |
| 为什么"同时"会不绝对？ | 因为光速有限且不变：传播距离差直接变成时间差 | [[05-同时性的相对性与因果律]] |
| 因果顺序会被颠倒吗？ | 不会。有因果关系的事件之间信号速度 $u \leqslant c$，$\Delta t'$ 与 $\Delta t$ 同号 | [[05-同时性的相对性与因果律]] |
