## 1 · 记号与约定

| 记号 | 含义 | 备注 |

## 3 · 五组公式（每组的条件都写出来了）

### 3.1 时空坐标变换

| | 伽利略变换（$v\ll c$） | 洛伦兹变换（任意 $v<c$） |
|---|---|---|
| $x'$ | $x-vt$ | $\gamma(x-vt)$ |
| $y',z'$ | $y,z$ | $y,z$ |
| $t'$ | $t$ | $\gamma\left(t-\dfrac{v}{c^2}x\right)$ |
| 逆变换 | $v\to-v$ | $x=\gamma(x'+vt')$，$t=\gamma\left(t'+\dfrac{v}{c^2}x'\right)$ |
| 不变量 | — | $c^2t^2-x^2$ |

### 3.2 三个时空效应

| 效应 | 公式 | 条件 | 等号/极限 |
|---|---|---|---|
| 同时性的相对性 | $\Delta t' = \gamma\left(\Delta t-\dfrac{v}{c^2}\Delta x\right)$ | 任意事件对 | $\Delta t'=0 \Leftrightarrow \Delta t=0$ 且 $\Delta x=0$ |
| 时间延缓（钟慢） | $\Delta t = \gamma\tau_0$ | $\tau_0$ 与事件**同地** | $v=0$ 时等号；**原时最短** |
| 长度收缩（尺缩） | $L = \dfrac{L_0}{\gamma} = L_0\sqrt{1-\beta^2}$ | 只沿**运动方向**；测长要**同时**测两端 | $v=0$ 时等号；**原长最长** |

**因果律判据**：$\Delta t'=\gamma\Delta t\left(1-\dfrac{vu}{c^2}\right)$，$\lvert u\rvert,\lvert v\rvert<c$ ⟹ 同号，**因果序不颠倒**。
（$\lvert\Delta x\rvert>c\lvert\Delta t\rvert$ 的类空间隔才可能出现时序颠倒。）

### 3.3 速度变换

$$
u_x = \frac{u_x'+v}{1+\dfrac{u_x'v}{c^2}},\qquad
u_y = \frac{u_y'\sqrt{1-\beta^2}}{1+\dfrac{u_x'v}{c^2}}
$$

逆变换：$v\to-v$（并把分母的 $+$ 变 $-$）。**要点**：$u'=c\Rightarrow u=c$；$u'<c$ 且 $v<c\Rightarrow u<c$。
光行差：$\tan\theta' = \dfrac{\sin\theta\sqrt{1-\beta^2}}{\cos\theta-\beta}$。

### 3.4 动力学

| 量 | 公式 | 条件/极限 |
|---|---|---|
| 相对论质量 | $m = \gamma m_0$ | $v\to c$ 时 $m\to\infty$；光子 $m_0=0$ |
| 动量 | $\vec p = \gamma m_0\vec v$ | $v\ll c$ 时 $\to m_0\vec v$ |
| 基本方程 | $\vec F = \dfrac{\mathrm{d}\vec p}{\mathrm{d}t} = m\dfrac{\mathrm{d}\vec v}{\mathrm{d}t}+\vec v\dfrac{\mathrm{d}m}{\mathrm{d}t}$ | $v\ll c$ 时 $\to m_0\vec a$（**$\vec F=m\vec a$ 高速失效**） |
| 动能 | $E_k = mc^2-m_0c^2 = (\gamma-1)m_0c^2$ | $v\ll c$ 时 $\to \frac12m_0v^2$ |
| 质能关系 | $E = mc^2$，$E_0 = m_0c^2$ | 任意系统 |
| 质量亏损 | $\Delta E = \Delta m_0c^2$ | 核反应、束缚态 |
| 速率–动能 | $v = c\sqrt{1-\left(\dfrac{m_0c^2}{E_k+m_0c^2}\right)^{2}}$ | $E_k\to\infty$ 时 $v\to c$ |

### 3.5 能量–动量关系

$$
\boxed{\;E^2 = p^2c^2+m_0^2c^4\;}
\qquad
E_k^2+2E_km_0c^2 = p^2c^2
\qquad
\text{光子：} E = pc
$$

低速极限（$E_k\ll m_0c^2$）：$E_k\approx\dfrac{p^2}{2m_0}$。

## 4 · 选题决策树

```
题目给的是什么？
│
├─ 两个事件 + 坐标/时刻 ──────────► 洛伦兹变换 Δt'=γ(Δt-vΔx/c²)，Δx'=γ(Δx-vΔt)
│
├─ "某钟走了多少"/"寿命" ────────► 先判原时：同地 ⟹ 原时 τ0
│                                    Δt = γτ0（原时最短）
│
├─ "长度"/"尺"/"飞船长" ──────────► 先判原长 L0：与杆静止的系
│                                    L = L0/γ（只沿运动方向；须同时测）
│
├─ 同一物体在两个系中的速度 ──────► 洛伦兹速度变换
│                                    （不能相加；分母 1+u'v/c²）
│
├─ 力/质量/动量 ─────────────────► p=γm0v，F=dp/dt，m=γm0
│
├─ 能量、结合能、质量亏损 ────────► E=mc²，E_k=mc²-m0c²，ΔE=Δm0c²
│
└─ 碰撞/衰变/光子散射 ────────────► 能量守恒 + 动量守恒（按分量）
                                     + E²=p²c²+m0²c⁴
```

## 6 · 陷阱清单（考前 3 分钟扫一遍）

| # | 陷阱 | 正确做法 |
|---|---|---|
| 1 | 原时/测时判反 | 同地的那只钟读数是原时（最短） |
| 2 | 原长/测长判反 | 与杆静止的系里量的是原长（最长） |
| 3 | $L=L_0/\gamma$ 用在垂直方向 | 垂直方向不收缩 |
| 4 | 忘记"同时测"是长度的前提 | 测长必须在同一系同时测两端 |
| 5 | 速度相加 $u=u'+v$ | 分母 $1+u'v/c^2$ |
| 6 | $\vec F=m\vec a$ | 用 $\vec F=\mathrm{d}\vec p/\mathrm{d}t$ |
| 7 | 对光子用 $E=\frac12mv^2$ | $E=pc$，$m_0=0$ |
| 8 | "能量为 $E$"当动能 | 通常指总能量；动能为 $E-m_0c^2$ |
| 9 | 复合粒子质量 = 各粒子之和 | 用能量守恒定 $M$；静质量不守恒 |
| 10 | 认为"质量变成能量" | $E=mc^2$ 是量度关系，质量亏损与能量释放是一回事 |
| 11 | 用舍入后的中间值继续算 | 保留足够有效数字（见 [[13-勘误与未解问题]] 的 π 介子例） |
| 12 | 单位混用（MeV 与 J） | $1\ \mathrm{MeV}=1.602\times10^{-13}\ \mathrm{J}$，$1\ \mathrm{MeV}/c=5.3443\times10^{-22}\ \mathrm{kg\cdot m/s}$ |
