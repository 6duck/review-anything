# 09 · 相对论质量与动量

> [!abstract] 一句话
> 为了让动量守恒在洛伦兹变换下对**所有**惯性系都成立，动量必须写成 $\vec p = m\vec v$ 而质量必须随速率变化：$m = \gamma m_0$。于是相对论动量 $\vec p = \gamma m_0\vec v$，基本方程仍是 $\vec F = \mathrm{d}\vec p/\mathrm{d}t$ —— 但 $\vec F = m\vec a$ 不再成立。

## 为什么需要它

前面四篇都是**运动学**（只谈坐标、时间、长度、速度）。从本篇起进入**动力学**：动量、能量、力。

课件 Ch05相对论02 p37 明确了建动力学时的三条原则：

| 原则 | 内容 |
|---|---|
| 相对性原则 | 基本规律在洛伦兹变换下形式不变 |
| 守恒原则 | 动量守恒、能量守恒等守恒定律在相对论力学中仍然成立 |
| 对应原则 | 低速时回到牛顿力学 |

**关键矛盾**：如果沿用 $m = m_0$（常量），那么在一个惯性系里守恒的动量，换到另一个惯性系后就不守恒了。这正是质量必须随速率变化的理由 —— 不是"实验发现质量变大了"，而是"守恒定律要成立就必须如此"。

## 对象与记号

| 记号 | 含义 |
|---|---|
| $m_0$ | 静质量（粒子静止时的质量） |
| $m = \gamma m_0$ | 相对论质量；$\gamma = 1/\sqrt{1-v^2/c^2}$ |
| $\vec p$ | 相对论动量，$\vec p = m\vec v = \gamma m_0\vec v$ |
| $\vec F$ | 合力；基本方程 $\vec F = \mathrm{d}\vec p/\mathrm{d}t$ |
| $v$ | 粒子相对**测量它的那个参考系**的速率（这就是"质量与哪个参考系有关"的含义） |

## 命题一：相对论质量（质速关系）

$$
\boxed{\;m = \frac{m_0}{\sqrt{1-\dfrac{v^2}{c^2}}} = \gamma m_0\;}
$$

**适用条件与极限行为**：

| 项目 | 内容 |
|---|---|
| 适用条件 | 粒子相对该参考系的速率为 $v$；$m_0$ 是与粒子相对静止的系中测得的质量 |
| 各向同性 | 由空间的各向同性，$m$ 与速度的**方向**无关，只与速率有关 |
| 低速极限 | $v\ll c$：$m\approx m_0$，回到牛顿力学 |
| 极限行为 | $v\to c$：$m\to\infty$（要把它加速到 $c$ 需要无限大的冲量） |
| 光子 | $v = c$ 而 $m$ 有限（$E/c^2$）⟹ 由质速关系**只可能 $m_0 = 0$** |

**课件给出的四条合理性检查（p40）**：① 最终由实验证明；② 空间各向同性 ⟹ $m$ 与速度方向无关；③ $v\ll c$ 时 $m\to m_0$；④ 光子 $v=c$ 而 $m$ 有限 ⟹ $m_0=0$。

## 命题二：相对论动量与基本方程

$$
\vec p = m\vec v = \frac{m_0\vec v}{\sqrt{1-v^2/c^2}},
\qquad
\boxed{\;\vec F = \frac{\mathrm{d}\vec p}{\mathrm{d}t}
= \frac{\mathrm{d}(m\vec v)}{\mathrm{d}t}
= m\frac{\mathrm{d}\vec v}{\mathrm{d}t}+\vec v\frac{\mathrm{d}m}{\mathrm{d}t}\;}
$$

> [!warning] $\vec F = m\vec a$ 在相对论中不成立
> 因为 $m$ 随速率变化，$\dfrac{\mathrm{d}m}{\mathrm{d}t}\neq0$（除非速率不变）。只有在 $v\ll c$（$m\approx m_0$ 为常数）时才退回 $\vec F = m_0\vec a$。
> 这个"多出来的项"$\vec v\,\mathrm{d}m/\mathrm{d}t$ 是相对论动力学与牛顿动力学最实质的差别，也是"力与加速度不再同方向"（除非力平行或垂直于速度的特殊情形）的根源。

**质量的物理含义**：课件 p42 写明 —— **质量的变化不是获得或失去，而是因速率变化而变化**。也就是说，"质量增大"不是往物体里加了物质，而是它的动能（以及相互作用能）本身贡献了惯性。

## 命题三：为什么必须是 $m=\gamma m_0$ —— 用一次对称碰撞推出来

课件只给出结论与理由（"按相对性原理和洛伦兹速度变换式，动量守恒表达式在任意惯性系中保持不变，应该有质速关系式"），没有展开。下面按这个思路补完：拿一次**对称的完全非弹性碰撞**，换到另一个惯性系里核对动量守恒，看质量**必须**长什么样。

**装置**：$S$ 系中两个全同粒子 A、B（各自静质量 $m_0$）以相同速率 $u$ 相向运动（A 沿 $+x$、B 沿 $-x$），碰后粘成一个复合粒子。

**① 先在 $S$ 系看**：总动量为零，故复合粒子静止；由能量守恒

$$2\gamma(u)m_0c^2 = M_0c^2 \;\Longrightarrow\; M_0 = 2\gamma(u)m_0 > 2m_0$$

复合粒子的静质量**大于**两粒子静质量之和，多出来的正是碰撞中损失的动能。

**② 换到 A 的静止系 $S'$**（$S'$ 相对 $S$ 以 $+u$ 运动）。此时 A 静止，B 的速度由洛伦兹速度变换给出：

$$u_B' = \frac{-u-u}{1+(-u)(u)/c^2} = -\frac{2u}{1+\beta^2},\qquad \gamma(u_B') = \frac{1+\beta^2}{1-\beta^2}\quad(\beta = u/c)$$

复合粒子在 $S$ 中静止，在 $S'$ 中就以 $-u$ 运动，质量 $\gamma(u)M_0 = 2\gamma^2(u)m_0$。

**③ 要求 $S'$ 中动量也守恒**（碰前只有 B 有动量）：

$$p'_{\text{前}} = -\gamma(u_B')\,m_0\,\frac{2u}{1+\beta^2} = -\frac{2m_0u}{1-\beta^2} = -2\gamma^2m_0u,\qquad p'_{\text{后}} = -\gamma(u)M_0u = -2\gamma^2m_0u$$

两边**恒等** —— 只要质量按 $m=\gamma m_0$ 变，动量守恒在洛伦兹换系下自动保持。

**④ 换成常量质量再试一遍**：若 $m\equiv m_0$，同样两步给出 $p'_{\text{前}} = -\dfrac{2m_0u}{1+\beta^2}$、$p'_{\text{后}} = -2m_0u$，两者相差因子 $1+\beta^2$ —— 取 $u=0.6c$ 时碰前只有碰后的 73%，**动量守恒破缺**。

| 口径（取 $u = 0.6c$，$\gamma = 1.25$） | $p'_{\text{前}}$ | $p'_{\text{后}}$ | 守恒？ |
|---|---|---|---|
| $m=\gamma m_0$ + 洛伦兹换系 | $-1.875\,m_0c$ | $-1.875\,m_0c$ | ✅ 恒等 |
| $m = m_0$ + 洛伦兹换系 | $-0.882\,m_0c$ | $-1.200\,m_0c$ | ❌ 差约 27% |
| $m = m_0$ + 伽利略换系 | $-1.200\,m_0c$ | $-1.200\,m_0c$ | ✅（经典力学与伽利略相对性原理自洽） |

> 表中数值为自己**手算代入**（$u_B' = 2u/(1+\beta^2) = 0.8824c$、$\gamma(u_B') = 2.125$、$M_0 = 2\gamma m_0 = 2.5m_0$），不需要任何程序。

**这张表说明的事**：

- 质速关系不是"高速下质量会变大"这种描述性说法，而是**要让动量守恒成为对所有惯性系都成立的定律，质量就必须随速率变**；
- 常量质量并不"错"，它与**伽利略**换系自洽 —— 换了换系规则，就得跟着换质量规律；
- 第 ① 步顺带给出"静质量不守恒"（$M_0 = 2.5m_0 > 2m_0$），这是 $E=mc^2$ 的另一面。


> [!tip] 这条核对把三个概念连成了一条线
> 相对性原理（守恒定律要在所有惯性系成立）+ 洛伦兹速度变换 ⟹ 质速关系 $m=\gamma m_0$。它同时也预告了 [[10-相对论动能与质能关系]] 的结论：**动能会以质量的形式出现**。

## 变体与边界

1. **完全非弹性碰撞会"增加"静质量**：见上面第 (1) 行的 $M_0 > 2m_0$。反过来，束缚态（如氦核）的静质量**小于**组分静质量之和（见 [[10-相对论动能与质能关系]] 的结合能计算）。两个方向都成立，说明静质量不是"守恒量"。
2. **斜向受力**：当 $\vec F$ 与 $\vec v$ 不平行时，$a_\parallel$ 与 $a_\perp$ 的有效"质量"不同（纵向质量 $\gamma^3m_0$、横向质量 $\gamma m_0$）。课件没有引入这两个概念 —— 只要求用 $\vec F=\mathrm{d}\vec p/\mathrm{d}t$，这是更简洁也更安全的做法。
3. **$\gamma\to\infty$ 的含义**：把粒子加速到 $c$ 需要无限冲量，所以 $c$ 是**运动学上限**；这与 [[08-洛伦兹速度变换]] 中"换系不可能超光速"是同一件事的两种说法。
4. **现代习惯**：很多教材已不再使用"相对论质量"，而是保留 $m_0$ 作为唯一的"质量"，把 $\gamma$ 放进动量与能量。两种写法等价，本笔记按课件采用 $m=\gamma m_0$。

## 常见错误

| 错误 | 正确认识 |
|---|---|
| 用 $\vec F = m\vec a$ 且把 $m$ 当常数 | 要用 $\vec F = \mathrm{d}(m\vec v)/\mathrm{d}t$，或写作 $m\vec a + \vec v\,\mathrm{d}m/\mathrm{d}t$ |
| 认为质量增大是"物质变多" | 是动能/相互作用能对惯性的贡献；课件：质量的变化因速率变化而变化 |
| 认为光子"有质量"或"没有动量" | 光子 $m_0 = 0$，但有能量因而有动量 $p = E/c$ |
| 把 $m_0$ 当作"实验室测到的质量" | $m_0$ 是**与粒子相对静止**的系中测得的质量 |
| 用 $\vec p=\gamma m_0\vec v$ 算低速问题 | 低速下 $\gamma\approx1$，直接用 $m_0\vec v$ 即可（对应原则） |

## 快速自测

> [!question]- 1. 为什么"动量守恒必须在所有惯性系成立"就足以否定 $m=m_0$？
> 因为动量守恒是含速度的定律，而速度按洛伦兹变换换系。若质量是常量，换系后 $\sum m\vec v$ 一般不再守恒（上文第 ④ 步：常量质量下碰前动量只有碰后的 $1/(1+\beta^2)$）。要让守恒律成为"定律"，质量必须随速率变。

> [!question]- 2. $v = 0.6c$ 时，粒子的质量是静质量的多少倍？动量比牛顿动量 $m_0v$ 大多少？
> $\gamma = 1/\sqrt{1-0.36} = 1.25$ 倍；动量 $p = 1.25m_0v$，比牛顿值大 25%。

> [!question]- 3. 若某粒子被外力持续加速，能否达到 $c$？
> 不能。$\mathrm{d}p = F\,\mathrm{d}t$ 给出的是有限的动量增量，而 $p = \gamma m_0v$ 在 $v\to c$ 时需要无限大动量。所以极限速率是 $c$（见 [[10-相对论动能与质能关系]] 的速率–动能关系式）。

> [!question]- 4. 碰撞后复合粒子的静质量可能小于两粒子静质量之和吗？
> 可能。静质量不守恒：放出能量（如辐射）时复合体静质量会**减小**（束缚能/质量亏损），吸收动能时静质量会**增大**（上文第 (1) 行 $M_0=2.1213>2$）。
