# 05 · 同时性的相对性与因果律

> [!abstract] 一句话
> $\Delta t' = \gamma\left(\Delta t - \dfrac{v}{c^2}\Delta x\right)$：在一个系中同时（$\Delta t=0$）但不同地（$\Delta x\neq0$）的两个事件，在另一个系中**一定不同时**。但只要两个事件有因果关系，它们的先后顺序在任何惯性系中都不会颠倒 —— 因为连接它们的信号速度不能超过 $c$。

## 为什么需要它

绝对时空观最核心的一条是"同时性是绝对的"：$t'=t$ 意味着一个系里同时的事，在另一个系里也同时。[[04-洛伦兹变换]] 的 $t'=\gamma(t-vx/c^2)$ 中含有 $-vx/c^2$ 项，**同一时刻但不同地点**的两个事件在 $S'$ 中的时刻必然不同 —— 绝对同时性随之失效。

这不是数学游戏，而是光速不变原理的直接后果。课件 Ch05相对论01 p36 的原话：**同时性的相对性是光速不变原理的直接结果。**

## 对象与记号

| 记号 | 含义 |
|---|---|
| 事件 1、事件 2 | 两个时空点 $(x_1,t_1)$、$(x_2,t_2)$ |
| $\Delta t = t_2-t_1$、$\Delta x = x_2-x_1$ | 两事件在 $S$ 系中的时间间隔、空间间隔 |
| $u = \Delta x/\Delta t$ | 若两事件有因果联系，则 $u$ 是连接它们的信号（或作用传播）速度 |
| $\Delta x'$、$\Delta t'$ | 同一对事件在 $S'$ 中的相应间隔 |

## 命题：同时性的相对性

对**任意一对事件**，由洛伦兹变换之差（不是对单个事件）得：

$$
\boxed{\;\Delta t' = \gamma\left(\Delta t - \frac{v}{c^2}\Delta x\right)\;}
$$

**讨论**：

| 情形 | 结论 |
|---|---|
| $\Delta t = 0$，$\Delta x \neq 0$（$S$ 中同时不同地） | $\Delta t' = -\gamma\dfrac{v}{c^2}\Delta x \neq 0$：**两事件不同时发生** |
| $\Delta t = 0$ 且 $\Delta x = 0$（同时同地） | $\Delta t' = 0$：两事件在 $S'$ 中也同时 |
| 一般情形 | 是否同时取决于两个系的选择：**"同时"是参考系相关的** |
| $v \ll c$ | $-\gamma v\Delta x/c^2 \to 0$，回到牛顿力学中的绝对同时性 |

> [!warning] 判据的精确表述
> "仅当 $\Delta t = 0$ **且** $\Delta x = 0$ 时，才有 $\Delta t' = 0$"（课件 Ch05相对论02 p19 原文）。
> 考试里最容易出错的是**漏掉 $\Delta x = 0$ 这一条**，从而把"两个事件同时"直接当成"在任何系中同时"。

## 爱因斯坦列车（思想实验，课件 p34–p36）

```
                    S'（爱因斯坦列车，以 v 向右运动）
   ┌──────────────────────────────────────────────┐
   │  A'◀────────────  M'  ────────────▶B'         │
   └──────────────────────────────────────────────┘
                       │  闪光
        ┌──────────────┴──────────────┐
        │ S' 系：A'M' = M'B'，光速各向为 c
        │  ⟹ A' 与 B' 同时接收到信号
        └──────────────┬──────────────┘
                       │ 换到 S（地面）
        ┌──────────────┴──────────────┐
        │ S 系：光速仍为 c，但 A' 迎着光跑、B' 躲着光
        │  ⟹ A' 先接收到，B' 后接收到
        └─────────────────────────────┘
             同一对事件：Δt' = 0，但 Δt ≠ 0
```

**关键**：整个推理**只用**"光速在两个系中都是 $c$"和"两端到中点等距"。既没有用到尺缩，也没有用到钟慢 —— 相反，钟慢与尺缩是它的推论。

## 命题：因果事件时序的绝对性

设两事件由信号（或作用）联系，其在 $S$ 中的传播速度为 $u = \Delta x/\Delta t$。把 $\Delta x = u\Delta t$ 代入：

$$
\Delta t' = \gamma\left(\Delta t - \frac{v}{c^2}u\Delta t\right)
= \gamma\,\Delta t\left(1-\frac{vu}{c^2}\right)
$$

**依据**：$\lvert u\rvert < c$（信号不能超光速，且这里讨论的事实上 $u\leqslant c$）与 $\lvert v\rvert < c$（两惯性系间相对速率小于 $c$），故

$$
\left\lvert\frac{vu}{c^2}\right\rvert < 1
\;\Longrightarrow\;
1-\frac{vu}{c^2} > 0
\;\Longrightarrow\;
\Delta t' \text{ 与 } \Delta t \text{ 同号}
$$

**结论**：有因果关系的事件，其时间顺序在任何惯性系中都不颠倒（课件 p20："相对论结果符合因果关系要求"。）

**反过来，时序何时可以颠倒？** 需要 $1-\dfrac{vu}{c^2}<0$，即

$$
\lvert u\rvert > \frac{c^2}{\lvert v\rvert} > c
$$

也就是说，**只有本来就不能用 $\leqslant c$ 的信号联系的两个事件（类空间隔），它们的时序才可能被不同参考系看成不同的先后**。这类事件之间没有因果可言，"颠倒"不构成佯谬。

> [!tip] 类时 / 类光 / 类空 三分（[补充]，把判据写成不依赖 $u$ 的形式）
> - $\lvert\Delta x\rvert < c\lvert\Delta t\rvert$（**类时**）：存在参考系使两事件同地，时序绝对，可以有因果；
> - $\lvert\Delta x\rvert = c\lvert\Delta t\rvert$（**类光**）：只能用光信号联系，时序绝对；
> - $\lvert\Delta x\rvert > c\lvert\Delta t\rvert$（**类空**）：不存在任何 $\leqslant c$ 的信号能联系它们，**存在参考系使它们同时**，也存在参考系使先后颠倒。

## 变体与边界

1. **"同时"的操作定义**：同一个惯性系内，用"光信号往返 + 钟读数取平均"来同步各处的钟。因为没有绝对同时性，**每个系必须各自同步自己的钟** —— 这解释了为什么"两个系测到的时间不同"不构成矛盾。
2. **同时性的相对性是可传递的吗？** 不是。"同时"并不构成一个可传递的等价关系：$A$ 与 $B$ 同时（在 $S$ 中）、$B$ 与 $C$ 同时（在 $S'$ 中）不能推出 $A$ 与 $C$ 同时。
3. **因果律是否被"时序颠倒"破坏？** 不。因果要求的是"因不晚于果"，而类空间隔的两个事件之间无因果可言。
4. **极限情形 $v\to0$**：$\Delta t'\to\Delta t$，恢复绝对同时性 —— 这是 [[01-经典时空观与伽利略变换]] 的适用范围。

## 常见错误

| 错误 | 正确认识 |
|---|---|
| "两个事件同时"不加限定语 | 必须说"在某个惯性系中同时" |
| 由 $\Delta t=0$ 直接断言 $\Delta t'=0$ | 还需要 $\Delta x=0$（同时同地） |
| 认为"高速运动使时间变慢"是原因 | 因果方向反了：**是同时性的相对性（以及光速有限）导致钟慢读数**，钟慢是结果 |
| 认为相对论允许回到过去 | 只有在类空间隔下才有"某个系看到颠倒"，而这种事件对之间没有因果、也没有任何物体或信号能走过这段间隔 |
| 把 $\Delta t' = \gamma(\Delta t-v\Delta x/c^2)$ 中的 $\Delta x$ 用 $S'$ 系的间隔 | 必须用 $S$ 系的 $\Delta x$（公式是"正变换"） |

## 快速自测

> [!question]- 1. 在 $S$ 系中同时发生的两个事件，是否一定存在某个惯性系使它们也不同时？若有，条件是什么？
> 一定有，只要 $\Delta x\neq0$：取任意 $v\neq0$ 的系即得 $\Delta t' = -\gamma v\Delta x/c^2 \neq0$。只有"同时且同地"（$\Delta t=\Delta x=0$）才是所有系都同时。

> [!question]- 2. 两个事件在 $S$ 中的间隔为 $\Delta x = 3\times10^{8}\ \mathrm{m}$、$\Delta t = 2\ \mathrm{s}$。它们可能有因果关系吗？能否找到使它们同时的参考系？
> $\lvert\Delta x\rvert = 3\times10^8 < c\Delta t = 6\times10^8\ \mathrm{m}$，属**类时**间隔：可能有因果，时序绝对不会颠倒，但**不可能**找到使其同时的参考系（需要 $v>c$）。

> [!question]- 3. 为什么"同时性的相对性"只需要光速不变原理，不需要知道任何关于钟或尺的相对论修正？
> 因为推理只比较"收到信号的时刻"：两端到中点等距 + 光速在两个系中都是 $c$ + 接收端随车移动，这三件事实已经足够。

> [!question]- 4. 若某参考系中测得两个无因果联系事件的时间顺序被颠倒，是否与相对论矛盾？
> 不矛盾。该类事件对是类空间隔，$\lvert\Delta x\rvert > c\lvert\Delta t\rvert$；存在与之相对运动的系使先后颠倒甚至同时。相对论只保证**因果**序不颠倒。
