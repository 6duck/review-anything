# 11 · 能量动量关系与相对论碰撞衰变

> [!abstract] 一句话
> $E^2 = p^2c^2+m_0^2c^4$ 把能量与动量统一成一个关系式（几何上是一个直角三角形），它在 $m_0=0$ 时给出光子的 $E=pc$。几乎所有相对论综合题（碰撞、衰变、介子寿命、光子–电子散射）都是"**能量守恒 + 动量守恒 + 这一条关系式**"三件套的联立。

## 为什么需要它

[[10-相对论动能与质能关系]] 给出 $E=mc^2$、[[09-相对论质量与动量]] 给出 $p=mv$，但两者都显式含有 $v$。在碰撞/衰变问题里，$v$ 往往不是已知量，需要消掉。$E$–$p$ 关系正好完成这件事：它只含 $E$、$p$、$m_0$ 三个量，且**对动量和能量都是二次式**，便于与守恒方程联立。

## 对象与记号

| 记号 | 含义 |
|---|---|
| $E = mc^2 = \gamma m_0c^2$ | 总能量（含静能） |
| $E_0 = m_0c^2$ | 静能 |
| $E_k = E-E_0$ | 动能 |
| $p = \gamma m_0v$ | 动量大小；$\vec p$ 为矢量 |
| $M$、$M_0$ | 复合粒子/母粒子的质量、静质量 |

## 命题一：能量–动量关系

$$
\boxed{\;E^2 = p^2c^2+m_0^2c^4\;}
$$

**推导（两行，只用定义）**：

$$
\begin{aligned}
E^2-p^2c^2 &= m^2c^4-m^2v^2c^2 &&\text{← 代入 } E=mc^2,\; p=mv\\
&= m^2c^4\left(1-\frac{v^2}{c^2}\right) &&\text{← 提取 } m^2c^4\\
&= m_0^2c^4 &&\text{← 质速关系 } m^2\left(1-v^2/c^2\right)=m_0^2
\end{aligned}
$$

**几何意义**：以 $pc$、$m_0c^2$ 为两条直角边，$E$ 为斜边，构成直角三角形（课件 p24 原话："能量与动量的统一性"）。

```
        E  ┌───────────────┐
          │╲              │
          │  ╲            │  m0c²
          │    ╲          │
          └──────╲────────┘
              pc
```

**适用条件**：任意粒子、任意速率（$0\leqslant v<c$）；对 $m_0=0$ 的光子同样成立。

## 命题二：用动能表示的形式

把 $E = E_k+m_0c^2$ 代入命题一：

$$
\left(E_k+m_0c^2\right)^2 = p^2c^2+m_0^2c^4
\;\Longrightarrow\;
\boxed{\;E_k^2+2E_km_0c^2 = p^2c^2\;}
$$

**低速极限**：当 $E_k\ll m_0c^2$（即 $v\ll c$）时，略去二阶小量 $E_k^2$：

$$
2E_km_0c^2 \approx p^2c^2
\;\Longrightarrow\;
E_k \approx \frac{p^2}{2m_0}
$$

**回到了牛顿力学的能量–动量关系式**。这是"对应原则"在这条公式上的体现，也是检验题目是否能用经典公式的判据：

| 判据 | 用什么 |
|---|---|
| $E_k \ll m_0c^2$（等价于 $v\ll c$） | 经典 $E_k = p^2/2m_0$ |
| $E_k$ 与 $m_0c^2$ 同量级或更大 | 相对论式 $E_k^2+2E_km_0c^2=p^2c^2$ |

## 命题三：光子

$m_0 = 0$ 时

$$
E^2 = p^2c^2 \;\Longrightarrow\; \boxed{\;E = pc,\qquad p = \frac{E}{c}\;}
$$

- 这就是"光的粒子性"在相对论里的表达：光子没有静质量，但**有动量**，两者由 $E=pc$ 联系。
- 由 $E = h\nu$ 得 $p = h\nu/c = h/\lambda$ —— 与 [[09-相对论质量与动量]] 中"$m_0=0$"的推导前后呼应。

## 例题

> [!example] 例 2 · 何时使用：已知能量（或动能）与静能求动量
> **题**：试计算能量为 $1\ \mathrm{MeV}$ 的电子的动量。（$1\ \mathrm{MeV}=10^6\ \mathrm{eV}$，电子的静止能 $m_ec^2 = 0.511\ \mathrm{MeV}$）
>
> **解（按题面字面：1 MeV 为电子的总能量 $E$）**：由 $E^2 = p^2c^2+(m_ec^2)^2$ 得 $pc = \sqrt{E^2-(m_ec^2)^2} = \sqrt{1^2-0.511^2}\ \mathrm{MeV} = 0.8596\ \mathrm{MeV}$。用换算 $1\ \mathrm{MeV}/c = 5.3443\times10^{-22}\ \mathrm{kg\cdot m/s}$，得 $p = 0.8596\times5.3443\times10^{-22}\ \mathrm{kg\cdot m/s} \approx 4.59\times10^{-22}\ \mathrm{kg\cdot m/s}$。
>
> ✅ verified：按课件自己写的方程 $(10^6\times1.6\times10^{-19})^2 = p^2(3\times10^8)^2+(0.511\times10^6\times1.6\times10^{-19})^2$ 解出 $p = 4.584\times10^{-22}$，与上面的 $4.59\times10^{-22}$ 一致。
>
> > [!bug] 但课件给出的答案是 $p = 7.57\times10^{-22}\ \mathrm{kg\cdot m/s}$
> > 这个数字对应的是"**把 1 MeV 当作动能**"的情形（$E = 1.511\ \mathrm{MeV}$，给出 $p \approx 7.58\times10^{-22}$）。
> > 也就是说，该页的**方程与答案不自洽**：方程按"总能量"写，答案按"动能"算。做题时以题面字面（总能量）为准，或向老师确认。详见 [[13-勘误与未解问题]]。

> [!example] 例 4 · 何时使用：给出总能量与静能，求速率、寿命、飞行距离（5-T1）
> **题**：快速运动的介子能量约为 $3000\ \mathrm{MeV}$，静止能量为 $100\ \mathrm{MeV}$，固有寿命为 $2\times10^{-6}\ \mathrm{s}$，求它的速度、平均寿命和运动的距离。
>
> **解**：
> 1. 由 $E = \dfrac{E_0}{\sqrt{1-v^2/c^2}}$ 得 $\dfrac{1}{\sqrt{1-v^2/c^2}} = \dfrac{E}{E_0} = 30$，解得 $v = 0.999c$。
> 2. 平均寿命（时间延缓）：$\tau = \dfrac{\tau_0}{\sqrt{1-v^2/c^2}} = 30\tau_0 = 6\times10^{-5}\ \mathrm{s}$。
> 3. 运动距离：$l = v\tau = 0.9994\times3\times10^{8}\times6\times10^{-5} \approx 1.8\times10^{4}\ \mathrm{m}$（约 18 km）。
>
> ✅ verified：$\gamma = 30$、$v = 0.999444c$、$\tau = 6.0\times10^{-5}\ \mathrm{s}$、$l = 1.799\times10^4\ \mathrm{m}$（手算复核）。
> **关键一步**：$E/E_0 = \gamma$ 是这类题的入口 —— 能量比直接给出 $\gamma$。

> [!example] 例 · 何时使用：两粒子对撞后粘在一起，问复合粒子的质量（课件 p26）
> **题**：两全同粒子以相同的速率相向运动，碰后复合。求复合粒子的速度和质量。
>
> **解**：
> 1. **动量守恒**：两粒子质量相同、速率相同、方向相反，总动量为零 ⟹ 复合粒子**静止**（$v'=0$）。
> 2. **能量守恒**：$2mc^2 = Mc^2$，其中 $m = \gamma m_0$、$M$ 是复合粒子的（静）质量：$M = 2m = \dfrac{2m_0}{\sqrt{1-v^2/c^2}} = 2\gamma m_0 > 2m_0$。
> 3. **对照**：若误用"静质量守恒"，会得到 $M = 2m_0$ —— 少了动能转化来的那一部分。**静质量不守恒**，这正是 $E=mc^2$ 的又一体现。
>
> ✅ verified：取 $v = 0.6c$ 时 $M = 2.5m_0 > 2m_0$（手算复核）。

> [!example] 例 6 · 何时使用：一个粒子衰变成两个，已知静质量求产物速率（课件 p29）
> **题**：静止质量为 $M$ 的粒子处于静止状态，它蜕变为具有静止质量 $m_1$、$m_2$ 的两个粒子，求质量为 $m_1$ 的粒子的速度。
>
> **解**：
> 1. **能量守恒**：$Mc^2 = E_1+E_2$；**动量守恒**：$0 = \vec p_1+\vec p_2$，故 $p_1 = p_2 \equiv p$（方向相反、大小相等）。
> 2. 两个粒子的能量–动量关系相减：$E_1^2-E_2^2 = \left(p_1^2-p_2^2\right)c^2+\left(m_1^2-m_2^2\right)c^4 = \left(m_1^2-m_2^2\right)c^4$（因为 $p_1 = p_2$，第一项为零）。
> 3. 左边用 $E_1^2-E_2^2 = (E_1-E_2)(E_1+E_2) = (E_1-E_2)Mc^2$，于是 $E_1-E_2 = \dfrac{m_1^2-m_2^2}{M}c^2$。
> 4. 与 $E_1+E_2 = Mc^2$ 联立：$E_1 = \dfrac{1}{2}\left[M+\dfrac{m_1^2-m_2^2}{M}\right]c^2 = \dfrac{M^2+m_1^2-m_2^2}{2M}c^2$。
> 5. 由 $E_1 = \dfrac{m_1c^2}{\sqrt{1-v_1^2/c^2}}$ 反解：$\boxed{\;v_1 = c\sqrt{1-\dfrac{4m_1^2M^2}{\left(M^2+m_1^2-m_2^2\right)^{2}}}\;}$。
>
> ✅ verified：取 $M=3$、$m_1=m_2=1$（单位 $m_0$），公式法与"先求 $E_1$ 再反解 $v_1$"两种算法手算一致，均得 $v_1 = 0.745356c$。

> [!example] 电子偶湮灭 · 何时使用：光子与静止电子散射，求电子最大速率（课件 p28）
> **题**：电子偶湮灭产生两个光子（每个能量 $E_\gamma = m_0c^2$）。其中一个光子与另一静止电子碰撞，求电子可获得的最大速率。
>
> **解**：要使电子速率最大，光子必须**背散射**（反向弹回），此时电子沿原光子方向飞出。
> 1. **能量守恒**：$E_\gamma+m_0c^2 = E_\gamma' + mc^2$，其中 $m = \gamma m_0$，$E_\gamma = m_0c^2$，故 $E_\gamma' = m_0c^2(2-\gamma)$。
> 2. **动量守恒**（取原光子方向为正）：$\dfrac{E_\gamma}{c} = -\dfrac{E_\gamma'}{c}+mv$，即 $m_0c = -m_0c(2-\gamma)+\gamma m_0v$。
> 3. 两边除以 $c$：$1 = -(2-\gamma)+\gamma\beta \Longrightarrow \gamma(1+\beta) = 3$。
> 4. 用 $\gamma(1+\beta) = \sqrt{\dfrac{1+\beta}{1-\beta}} = 3$ 得 $\dfrac{1+\beta}{1-\beta} = 9$，解得 $\beta = \dfrac{4}{5}$，即 $v = 0.8c$。
>
> ✅ verified：手算 $\gamma(1+\beta) = \sqrt{(1+\beta)/(1-\beta)} = \sqrt{9} = 3$ ✓

> [!example] 综合练习 5-T3 · 何时使用：物体在两个系中的倾角不同
> **题**：$S$ 与 $S'$ 是坐标轴相互平行的两个惯性系，$S'$ 相对 $S$ 沿 $x$ 轴正向匀速运动。一根刚性尺静止在 $S'$ 中，与 $x'$ 轴成 $30^\circ$ 角；今在 $S$ 系中观察得该尺与 $x$ 轴成 $45^\circ$ 角，则 $S'$ 相对 $S$ 的速度是多少？
>
> **解**：令 $\Delta x = \Delta x'\sqrt{1-v^2/c^2}$、$\Delta y = \Delta y'$（纵向收缩、横向不变），则 $\tan 45^\circ = \dfrac{\Delta y}{\Delta x} = \dfrac{\Delta y'}{\Delta x'}\cdot\dfrac{1}{\sqrt{1-v^2/c^2}} = \tan 30^\circ\cdot\dfrac{1}{\sqrt{1-v^2/c^2}}$。
> 代入 $\tan45^\circ = 1$、$\tan30^\circ = 1/\sqrt3$ 得 $\sqrt{1-v^2/c^2} = \dfrac{1}{\sqrt3}$，即 $\dfrac{v^2}{c^2} = \dfrac{2}{3}$，故 $v = \sqrt{\dfrac{2}{3}}\,c \approx 0.816c$。
>
> ✅ verified：$\sqrt{2/3} = 0.8165c$（手算），与课件答案 $v = \sqrt{2/3}\,c$ 一致。
> **要点**：$S'$ 中角度**小**（30°）、$S$ 中角度**大**（45°）—— 运动方向被压短，物体"看起来更陡"。

> [!example] 综合练习 5-T2（选择题，详解见 [[07-长度收缩]]）
> 飞船长 $90\ \mathrm{m}$（船系）、以 $0.8c$ 飞行，光脉冲从船尾传到船头，地球观察者测得两事件的空间间隔为 270 m（选项 C）。**陷阱**：这不是"测长"，所以不能用 $90/\gamma = 54\ \mathrm{m}$。

## 变体与边界

1. **一定要用矢量动量守恒**：$E^2=p^2c^2+m_0^2c^4$ 里的 $p$ 是**大小**；守恒式里必须按分量写（上面光子–电子一题就是用"反向"把矢量变成一维）。
2. **$E_k^2$ 何时可以略去**：判据是 $E_k\ll m_0c^2$。若题目给出 $E_k = 1\ \mathrm{MeV}$ 而 $m_0c^2 = 0.511\ \mathrm{MeV}$，就不能略去（这也是上引例 2 争议的根源）。
3. **光子没有"静质量"但有"等效质量"**：由 $E=mc^2$ 可以说光子的等效质量是 $E/c^2$，但它**没有静止系**，所以不能有 $m_0$。
4. **多产物衰变**：例 6 的方法（能量守恒 + 动量守恒 + 关系式）可推广到任意产物数，但产物多于两个时未知量增加，需要更多条件（如共线、对称）。
5. **低速极限**：$E_k = p^2/2m_0$ 与经典一致；$E\approx m_0c^2+p^2/2m_0$，即"静能 + 经典动能"。

## 常见错误

| 错误 | 正确认识 |
|---|---|
| 把"能量"一律当动能 | 题目说"能量为 $E$"通常指**总能量** $mc^2$；"动能为 $E_k$"才是 $E-m_0c^2$。上引例 2 的争议正来自这里 |
| 对光子使用 $E = \frac12mv^2$ 或 $p=mv$ | 光子用 $E = pc$，且 $m_0=0$ |
| 在动量守恒里只用大小 | 必须按方向（分量）写；背散射与同向散射结果不同 |
| 认为"复合粒子质量 = 各粒子质量和" | 静质量不守恒；要用能量守恒定出 $M$ |
| 忘记 $1\ \mathrm{MeV}$ 与 $\mathrm{kg\cdot m/s}$ 的换算 | $1\ \mathrm{MeV}/c = 5.3443\times10^{-22}\ \mathrm{kg\cdot m/s}$；见 [[12-速查表]] |

## 快速自测

> [!question]- 1. 一个电子的总能量是静能的 3 倍，它的动量是多少（用 $m_ec$ 表示）？
> $E = 3m_ec^2$，$m_0c^2 = m_ec^2$，故 $pc = \sqrt{9-1}\,m_ec^2 = 2\sqrt2\,m_ec^2$，即 $p = 2\sqrt2\,m_ec$。

> [!question]- 2. 为什么"静质量不守恒"不等于"能量不守恒"？
> 因为守恒的是总能量（包含动能），而静质量只对应静能那一部分。动能与静能之间可以互相转化：对撞复合时 $M>2m_0$（吸能），束缚时 $M<2m_0$（放能）。

> [!question]- 3. 在例 6 中，如果 $m_1 = m_2$，$v_1$ 化简成什么？
> $v_1 = c\sqrt{1-4m_1^2M^2/(M^2)^2} = c\sqrt{1-4m_1^2/M^2}$。再结合 $M\ge 2m_1$ 可知根号内非负，$M = 2m_1$ 时 $v_1 = 0$（两粒子都静止，只有静能）。

> [!question]- 4. 若题目给出 $E_k = 1\ \mathrm{GeV}$、$m_0c^2 = 0.938\ \mathrm{GeV}$（质子），能否用经典 $E_k = p^2/2m_0$？
> 不能，因为 $E_k$ 与 $m_0c^2$ 同量级（$E_k^2$ 项不能略去）。应使用 $E_k^2+2E_km_0c^2 = p^2c^2$，或直接用 $E = E_k+m_0c^2$ 与 $E^2 = p^2c^2+m_0^2c^4$。
