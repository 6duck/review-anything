# 13 · 勘误与未解问题

> [!abstract] 这一页只收"知识点错误"
> 判据：**跟着它学会学错**的才收 —— 公式错、数值与自己的方程矛盾、结论丢了前提、引用张冠李戴。
> 错别字、字体、页码顺序、自己渲染时掉字之类不影响结论的问题不收（E 节列了已排除的几类，供对照）。
> 每一条给出：出处 → 现象 → 手算复核 → 影响程度 → 建议做法。

## A · 已核实的课件问题

### E1 ★高｜Ch05相对论03 p25 例 2：方程与答案不自洽

**现象**：题目问"能量为 $1\ \mathrm{MeV}$ 的电子的动量"，课件写出的方程是

$$
\left(10^6\times1.6\times10^{-19}\right)^2 = p^2\left(3\times10^8\right)^2+\left(0.511\times10^6\times1.6\times10^{-19}\right)^2
$$

（左边 $E = 1\ \mathrm{MeV}$ 是**总能量**），但给出的答案是 $p = 7.57\times10^{-22}\ \mathrm{kg\cdot m/s}$。

**手算复核**：

| 口径 | $pc$ | $p$（$\mathrm{kg\cdot m/s}$） |
|---|---|---|
| 按方程（1 MeV = **总能量**） | $\sqrt{1^2-0.511^2} = 0.8596\ \mathrm{MeV}$ | $4.584\times10^{-22}$ |
| 按课件答案反推（1 MeV = **动能**，$E = 1.511\ \mathrm{MeV}$） | $\sqrt{1.511^2-0.511^2} = 1.422\ \mathrm{MeV}$ | $7.58\times10^{-22}$ |

**结论**：课件把"能量"当成了"动能"来算（或反之），方程与答案矛盾。

**影响**：直接照抄答案会与题目条件冲突；考试中若遇到同类题，必须先明确"能量"指总能量还是动能。

**建议**：按题面字面用总能量（$p = 4.59\times10^{-22}\ \mathrm{kg\cdot m/s}$），并在考后向老师确认题目的原始提法。

### E2 ★中｜Ch05相对论01 p23：$\Delta N$ 的数值对不上代入值

**现象**：课件给 $L_1+L_2 = 22\ \mathrm{m}$、$v = 3\times10^{4}\ \mathrm{m/s}$、$\lambda = 589\ \mathrm{nm}$，结论写 $\Delta N = 0.40$。

**手算复核**：$\Delta N = \dfrac{L_1+L_2}{\lambda}\cdot\dfrac{v^2}{c^2} = \dfrac{22}{589\times10^{-9}}\times\left(\dfrac{3\times10^4}{3\times10^8}\right)^2 = 0.3735 \approx 0.37$。

反推使 $\Delta N = 0.40$ 所需的速度为 $v \approx 3.105\times10^{4}\ \mathrm{m/s}$ —— 与"地球公转速率"的常见取值 $3.0\sim3.1\times10^{4}\ \mathrm{m/s}$ 相符。

**影响**：低。结论（"预期约 0.4 条条纹移动、实测为 0"）不受影响。

**建议**：引用时写"$\Delta N$ 约为 $0.4$（按 $v=3.0\times10^4\ \mathrm{m/s}$ 精算为 $0.37$）"。

### E3 ★低｜Ch05相对论02 p35（=03 p6）例 4：中间值舍入导致距离不自洽

**现象**：$\pi$ 介子题中课件写 $\Delta t = 1.8\times10^{-7}\ \mathrm{s}$，并给飞行距离 $L = 52.6\ \mathrm{m}$。

**手算复核**：未舍入的 $\Delta t = \gamma\tau_0 = 7.0888\times2.5\times10^{-8} = 1.7722\times10^{-7}\ \mathrm{s}$，对应 $L = 0.99c\times1.7722\times10^{-7} = 52.63\ \mathrm{m}$ ✅；
但若用课件写出的舍入值 $1.8\times10^{-7}\ \mathrm{s}$ 反算，则 $L = 53.46\ \mathrm{m}$（差 0.86 m）。

**影响**：低（只影响最后一位有效数字），但**是典型的"中间值舍入"陷阱**。

**建议**：计算时保留 $\Delta t = 1.77\times10^{-7}\ \mathrm{s}$ 或用符号式 $L = v\gamma\tau_0$ 一次算完。

### E4 ★中｜Ch05相对论02 p41：光子静止质量实验的文献引用需核对

**现象**：课件正文标注该实验的文献为 **PRL 91 (2003) 149102** 与 **PLA 352 (2006) 267**。

**核对结果**（📖 经网络检索）：这类"旋转扭秤法测光子静止质量上限"的**原始实验论文**是
*New experimental limit on the photon rest mass with a rotating torsion balance*，**Phys. Rev. Lett. 90, 081801 (2003)**（作者为华中科技大学罗俊、涂良成、胡忠坤、栾恩杰等）。

**判断**：PRL 91, 149102 (2003) 并非该方法的主论文（可能是同期的评论/答复类文章，⚠️ 未能取得原文确认）。

**影响**：中 —— 若按课件引文去查文献，可能找不到实验细节。

**建议**：引用时同时给出 PRL 90, 081801 (2003)（原始实验）与课件所列文献，并注明出处待核。

### E5 ★低｜Ch05相对论02 p41：同一页两个"质量数字"性质不同

**现象**：正文写 $m_\gamma = (0.9\pm1.5)\times10^{-52}\ \mathrm{g}$（测量值 ± 误差，与零相容），而同一页表格最后一行为 "Our result 2002, Dynamic torsion balance, $1.2\times10^{-51}\ \mathrm{g}$"（上限）。

**影响**：低，但引用时极易把"测量值"与"上限"混为一谈。

**建议**：写清"$m_\gamma$ 的上限在 $10^{-51}\sim10^{-52}\ \mathrm{g}$ 量级"。

### E6 ★低｜Ch05相对论01 p16–p17：结论省略了前提

**现象**：课件结论写"空间任何两点间的距离，在任何一个惯性参考系中测量，都是绝对相等的"。

**问题**：这句话成立的前提是**两端同时测量**（即 $\Delta t = 0$）。课件在该页的公式推导中出现了这个条件（原文为"测量距离两端要求…进行"，应为"要求同时进行"），但结论句里没有重申。

**影响**：低，但在相对论部分（同时性不再绝对）如果不加区分地套用，会与本篇的"原长最长"直接冲突。

**建议**：把结论改写成"在两端同时测量的前提下，空间两点的距离在伽利略变换下绝对相等"。

## B · 抽样式复核（只查了 3 处最高风险数值）

物理类笔记的数值只做**抽样复核**：3 项、手算。抽样是为了抓"系统性算错"，不是把每个数字重算一遍 —— 后者既耗时，也说明不了更多。

| 抽到的项 | 课件 | 手算 | 结论 |
|---|---|---|---|
| 氦核结合能链 $\Delta M \to \Delta E \to \Delta E_{\mathrm{mol}}$ | 0.03038 u / $4.539\times10^{-12}$ J / $2.733\times10^{12}$ J | 0.03038 u / $4.5388\times10^{-12}$ / $2.7332\times10^{12}$ | 一致 |
| 迈克耳孙 $\Delta N$（风险最高：与课件给的 0.40 不符） | 0.40 | 0.3735 | **不一致** → E2 |
| 1 MeV 电子动量（E1 的争议值） | $7.57\times10^{-22}$ | $4.59\times10^{-22}$（总能量口径） | **不一致** → E1 |

其余结论性数值（长度收缩、速度合成、质心系速率、$\pi$ 介子寿命与距离、介子 $\gamma$ 与 $v$、衰变产物速率、电子偶湮灭最大速率、5-T2 空间间隔、5-T3 倾角、时间延缓等）**本次未逐项复核**；与课件有出入的地方已在正文相应位置标 ⚠️。需要时可照上表方法再抽 3 项。
