# _sources · 原始素材与中间产物

本目录是 `相对论复习笔记` 的**可追溯层**：笔记里每一个数字、公式和结论都能在这里找到出处。

## 素材（原件不在本目录，路径为只读引用）

| 文件 | 页数 | 文字层情况 | 提取路线 |
|---|---|---|---|
| `<素材目录>\Ch05相对论01.pdf` | 36 | 4 页无文字层（p1、p25、p29、p30） | 文字路线 + 视觉转录 |
| `<素材目录>\Ch05相对论02.pdf` | 43 | 3 页无文字层（p26、p29、p30） | 文字路线 + 视觉转录 |
| `<素材目录>\Ch05相对论03.pdf` | 35 | 1 页无文字层（p1） | 文字路线 + 视觉转录 |

判定依据：**近零字符页占比**（课件型 PDF，平均 181–215 字符/页；近零字符页占比 0–2%）。
提取命令（可用 review-anything 的脚本随时重跑）：

```bash
python <review-anything>/scripts/extract_material.py Ch05相对论01.pdf --out _sources/src-Ch05相对论01.txt
python <review-anything>/scripts/extract_material.py Ch05相对论01.pdf --render-png ./_extract/pages01 --dpi 150 --pages 1,25,29,30
```

> Windows 注意：控制台默认 GBK，脚本末尾会用 `✓` 打印对账信息，需先设 `PYTHONIOENCODING=utf-8` 才不会报 `UnicodeEncodeError`（提取本身不受影响，文件已写出）。

## 如何复核本笔记

```bash
# 结构与链接自检（编号连续性、公式配对、wikilink、断链）
python <review-anything>/scripts/check_notes.py .
```

数值与结论的复核方式：

1. **数值**：按 [[13-勘误与未解问题]] B 节的三个抽样式列式自行代入（每项都是一两步算术）；
2. **机制**：按 [[09-相对论质量与动量]] "用一次对称碰撞推出来"的四步自行推一遍 —— 这是本类笔记的标准核验方式，不需要跑程序；
3. **出处**：取值、公式、图号一律回到上表的 PDF 页（`src-*.txt` 里有带页码的全文）。

要加新内容时：按 [[00-总览与知识链]] 的编号槽位追加 `14-`、`15-`…（新增正文篇时，速查表与勘误顺延），并把新课件同样提取到本目录。
